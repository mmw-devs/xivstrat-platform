# 图片随攻略投稿：实施记录

目标：飞书 H5 编辑，腾讯云后端仅做有容量上限的临时中转，JSON 和图片进入同一个 GitHub commit / PR。不引入 COS、云端草稿或长期服务器图库。

## 本地阶段（本分支）

- 正文与封面共享内存素材集合，原始文件不写入服务器。
- PNG、JPEG、静态 WebP 可转换为高质量有损 WebP；不会将 canvas 的质量参数宣称为无损。当前浏览器必须具备 createImageBitmap、WebP canvas 编码及 Web Crypto 能力。
- 成品文件按 SHA-256 命名，JSON 保留相对于 content/ 的 assets/images/<hash>.webp 引用，object URL 只用于显示。
- 输入最大 20 MiB / 2500 万像素；成品最大 3 MiB；内存素材集合最多 60 MiB（包括移除后暂保留的素材）。
- ZIP 使用 strategy.json 加 assets/images/，只打包引用到的本地图片；外链不下载。最多 30 个图片引用，JSON 最大 1 MiB，包内合计最大 20 MiB。
- ZIP 导入限制文件路径、数量、声明解压大小和图片哈希，校验成功后替换文档。无对应文件的旧相对引用需要作者重新选图。
- 本地图片投稿在前端和服务端明确阻止，防止旧的 JSON-only 通路创建缺图 PR。
- 关闭页面前需自行下载 ZIP。JSON 下载不包含图片，未提供云端保存或跨设备自动恢复。
